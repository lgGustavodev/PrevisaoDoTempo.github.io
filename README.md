# Previsão do Tempo

Um aplicativo simples para visualizar a previsão do tempo de diversas cidades.

## Recursos

- Busca por cidade.
- Exibe temperatura atual, máxima e mínima.
- Exibe descrição do clima.
- Exibe umidade.
- Exibe velocidade do vento.

## Como usar

1. Clone o repositório:

    ```bash
    git clone https://github.com/<seu-usuario>/PrevisaoDoTempo.github.io.git
    ```

2. Navegue até o diretório do projeto:

    ```bash
    cd PrevisaoDoTempo.github.io
    ```

3. Abra o arquivo `index.html` no seu navegador preferido.
